# Phase 2 — Core Completeness (implementation plan)

**Spec:** `docs/ROADMAP.md` → "Phase 2: Core Completeness" (work items P2-1..P2-11).
**Branch strategy:** two PRs off `main`, safe → risky.
**Validation:** GitHub Actions CI only — nothing is built or tested locally
(`cargo test -p notetaker-core` runs in the `core` job on Linux; the
`test-transcription` job runs the real-model WAV smoke test). Each work item is
its own commit so CI can attribute a compile/test break.

## Global constraints

- No local `cargo`/`gradle`/`xcodebuild`. Reason carefully about types; let CI compile.
- One work item per commit; descriptive messages; push early, keep PR in draft until green.
- The committed `core/include/notetaker.h` is hand-edited to match what
  `build.rs`/cbindgen would emit (same `//` doc-comment style, functions in
  source order). A CI gate (`git diff --exit-code core/include/notetaker.h`
  after the core build) proves the hand edit matches the generator.
- JSON shapes returned across FFI are the contract Swift/Kotlin/C# decode.
  **Do not add fields to `Meeting`** (Kotlin's serializer rejects unknown keys).

## PR A — foundations + FFI + cloud (safe)

Order chosen so later items build on earlier: schema first, then tests, then
error surface, then the new FFI, then cloud, then the CI gates that make them real.

### A1 — P2-8 Schema versioning
- `storage.rs`: `PRAGMA user_version`; a `MIGRATIONS: &[&str]` array; on `open`,
  read version, run pending migrations in a transaction, set new version.
- Migration 1 = the current `CREATE TABLE IF NOT EXISTS …` body (so a fresh DB
  and a Phase-1 DB both converge). Keep `CREATE … IF NOT EXISTS` so existing
  Phase-1 DBs (user_version=0 with tables already present) don't error.
- Migration 2 = `CREATE TABLE meeting_summaries` (see A5).
- Tests (A2) assert `user_version` advances and is idempotent across two opens.

### A2 — P2-3 Test suite  (`core/tests/`)
- `storage_tests.rs`: open `:memory:`; schema/user_version; meeting CRUD;
  segment insert/get; FTS5 search (match + injection-safety: a query containing
  `"` or FTS operators returns without error); cascade delete; export md/text/json.
- `models_tests.rs`: serde round-trip for Meeting / TranscriptSegment / Summary / Note.
- `ffi_tests.rs`: `note_init`(temp file)/`note_destroy`; null-pointer calls return
  the right codes / null; double `note_stop_recording` is safe; `note_last_error`
  after a forced failure (A3); getters on empty DB.
- Target ≥20 tests. No whisper model here (core job has none). Transcriber
  pure-logic tests arrive with B4.

### A3 — P2-2 Error reporting
- Thread-local `LAST_ERROR: RefCell<Option<CString>>`; `set_last_error(msg)`
  helper called on FFI error paths (incl. `note_init` → null).
- `note_last_error() -> *mut c_char` (caller frees with `note_free_string`;
  null when none). No handle arg.
- `note_set_log_callback(cb, ctx)`: install a `log::Log` that forwards records to
  the C callback; worker-thread errors reach consumers this way.

### A4 — P2-1 FFI surface
- `Database::update_meeting_title(id, &str)`; `Database::search_meetings_full`
  (ids → `Vec<Meeting>`, newest first) so search returns decodable meetings.
- New FFI fns: `note_resume_recording` (→ `AudioCapture::resume`),
  `note_search_meetings(handle, query) -> char*` (JSON array of Meeting),
  `note_get_segments(handle, meeting_id) -> char*` (JSON array),
  `note_update_meeting_title(handle, meeting_id, title) -> i32`.
  (`note_get_audio_level` already exists.)
- Hand-edit `core/include/notetaker.h`.

### A5 — P2-4 Cloud summarization
- `summarize.rs`: 30s client timeout (`Client::builder().timeout(..)`); strip
  ```json fences before `serde_json::from_str`; keep structured `Summary`.
- Store structured summary in `meeting_summaries` (migration 2):
  `meeting_id PK, summary TEXT, key_points TEXT(json), action_items TEXT(json),
  decisions TEXT(json)`. `note_summarize` writes it and still returns the JSON.
- Add `Database::get_summary(meeting_id) -> Option<Summary>` + optional getter FFI.

### A6 — CI gates
- `.github/workflows/build.yml`: core-job `cargo test` → `--features cloud`
  (so A5 compiles+tests in CI). Add header-drift gate after core build.
- `scripts/build-core.sh`: add `CORE_FEATURES` env appended to each `cargo build`.
  **Risk:** `cloud`→`reqwest`→`ring` on the Android cross-compile shares the
  Linux `core` job; if it breaks the Linux core artifact, scope `cloud` to
  non-Android targets and note for P3-11. Ruling recorded if hit.

## PR B — transcriber redesign + Linux (risky)

**Blocking read before any `transcribe.rs` edit:** `linux/src/core_bridge.rs`
(calls `LocalTranscriber::new` directly; `app-linux` is `if-no-files-found:
error`) and `linux/src/views/*.rs`.

**One transcriber signature, designed once** (serves B1–B4):
`LocalTranscriber::new(ctx: Arc<WhisperContext>, config: TranscriberConfig,
audio_rx, db, meeting_id, callback)`. Three call sites updated together:
`lib.rs`, `core/src/bin/transcribe_wav.rs`, `linux/src/core_bridge.rs`.

- **B1 — P2-7 model cache.** `WhisperContext` loaded once, cached on `NoteHandle`
  keyed by resolved model file path (`Mutex<Option<(String, Arc<WhisperContext>)>>`),
  loaded lazily on first `start_recording`. `transcribe_wav.rs` loads its own ctx.
- **B2 — P2-9 config.** `TranscriberConfig { language (default "en", "auto"
  allowed), n_threads (default 4) }` read from settings in `lib.rs`.
- **B3 — P2-5 push-audio.** `note_start_recording_push(handle)` (no `AudioCapture`;
  stores `audio_tx` on handle) + `note_push_audio(handle, *const f32, usize)`.
  CI proof: `transcribe-wav --via-ffi` path + a CI step asserting "country".
- **B4 — P2-6 streaming quality** (separate commits, CI bisects each):
  (a) extract pure chunk logic (overlap/dedup/VAD/30s cap) into a whisper-free
  struct with unit tests in the core job; (b) 1s overlap; (c) one `WhisperState`
  per session + `set_no_context(false)`; (d) energy VAD skips silence; (e) cap
  buffer at 30s with backpressure.
- **B5 — P2-10 Linux model download** (settings.rs): HTTP GET from HuggingFace to
  models dir with a progress indication.
- **B6 — P2-11 Linux polish**: enable `cloud` in `linux/Cargo.toml`; wire
  summarize to `CloudSummarizer`; `GtkFileDialog` export; `AdwToast` errors; FTS5
  search in history; pause/resume button; `set_hide_on_close` re-present.
  Compile-only for me, unrunnable for the user on macOS → keep minimal, do last.

## Review focus (for the final whole-branch reviewer)

- FFI memory/ownership: every `char*` return is caller-freed; no double-free;
  null handled on every new fn; `catch_unwind` wraps every new `extern "C"` fn.
- Migration idempotency on a pre-existing Phase-1 DB (tables present, user_version=0).
- Transcriber: state reuse across chunks with `no_context(false)` doesn't leak or
  double-emit segments; overlap doesn't duplicate text at chunk boundaries;
  shutdown still drains queued audio (Phase-1 fix must survive the refactor).
- `note_push_audio` + mic path can't both feed one session.
- Thread-local last-error semantics across the FFI thread vs worker threads.
